# 📝 Form Validator

### A responsive form validation project built using HTML, CSS, and JavaScript.
A form validation application that checks user input and provides dynamic error and success feedback to ensure that entered information meets the required validation rules.

## ✨ Features

- Required field validation
- Username length validation (3–15 characters)
- Email format validation using Regular Expressions
- Password length validation (6–25 characters)
- Password confirmation matching
- Dynamic error and success messages
- Visual feedback for invalid and valid inputs
- Form reset after successful validation

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation & Event Handling)

---

## 🔍 Validation Rules

| Field | Requirements |
|---|---|
| Username | 3–15 characters |
| Email | Valid email format |
| Password | 6–25 characters |
| Confirm Password | Must match the password |
| All Fields | Required |

---

## ⚙️ How It Works

When the user submits the form:

1. Prevents the default form submission behavior.
2. Checks that all required fields are filled in.
3. Validates username and password lengths.
4. Validates the email format.
5. Checks if the password and confirmation password match.
6. Displays error messages or success states for each field.
7. Shows a success message and resets the form if all validations pass.
